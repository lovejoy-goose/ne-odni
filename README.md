# Не одни

Жуткий картонный VR для телефона: через заднюю камеру видна ваша комната, и в ней появляется существо.

https://lovejoy-goose.github.io/ne-odni/

## Авторство
- Модель существа: [«tall figure in dark»](https://sketchfab.com/3d-models/tall-figure-in-dark-93cee5d144e14e5babbdafd5dcf0a411), автор nanonova, лицензия [CC BY 4.0](http://creativecommons.org/licenses/by/4.0/). Изменения: масштаб и центровка, собственный шейдер, анимация головы.
- three.js (MIT).
- Звуки (CC0, [OpenGameArt](https://opengameart.org)): [Ambient Horror](https://opengameart.org/content/ambient-horror), [Footsteps](https://opengameart.org/content/footsteps-0), [Light switch](https://opengameart.org/content/light-switch-turn-on-and-off-sfx-0), [Dialog vocal samples](https://opengameart.org/content/dialog-vocal-samples) (шёпот). Переконвертированы в AAC.
